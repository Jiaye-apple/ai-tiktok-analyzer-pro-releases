## English

### What is AI TikTok Analyzer Pro?

AI TikTok Analyzer Pro is a TikTok research and analytics tool that combines a browser extension with a web workbench. It helps creators, influencer marketers, TikTok Shop sellers, agencies, and cross-border ecommerce teams study public videos, compare content performance, understand comments, and organize research.

Use the extension while browsing TikTok to sort videos, export comments, transcribe speech, translate content, analyze scripts, and download media you are authorized to use. The web workbench provides related tools and research workflows. Start with a specific question—such as which videos attract the most discussion or what buyers keep asking—and build a reviewable set of examples.

### Core features

| Feature | What you can do | Useful for |
|---|---|---|
| TikTok video sorting and filtering | Sort loaded videos by views, likes, comments, shares, or posting time; narrow results by keyword, date, and metric ranges. | Finding content worth studying on a public creator profile. |
| TikTok comment export | Export loaded public comments to a spreadsheet, with available fields such as text, likes, timestamps, and reply relationships. | Audience research, reporting, and organizing customer questions. |
| Comment translation | Translate public comments and compare them with the original text. | Researching audiences across languages and markets. |
| AI comment analysis | Summarize recurring themes, sentiment, questions, and objections in collected comments. | Turning audience feedback into topics and product messaging. |
| Video transcription and subtitles | Convert video speech into text, inspect available subtitles, and work with translated transcripts. | Reviewing spoken scripts and preparing multilingual briefs. |
| AI script and hook analysis | Break down the opening, structure, key points, and calls to action in a video. | Planning original scripts and comparing storytelling approaches. |
| Creator analytics | Review available profile information and video-level engagement metrics. | Comparing creators and assessing a shortlist for further research. |
| Video and batch downloads | Save authorized media individually or from a filtered selection. | Keeping reference material for permitted research and archiving. |
| Hashtag research | Inspect tags used in loaded content and explore hashtag ideas through the web tools. | Developing topics and organizing a content plan. |
| Research collections | Organize selected creators and videos into collections. | Keeping a project focused and returning to promising examples. |

Sorting and page-based statistics depend on the content available and loaded in your browser. Comment analysis reflects the collected sample; it should not be treated as a complete survey of an audience. Feature access and usage limits depend on the browser, account, and current plan.

See the [complete extension feature guide](https://tiktok.poviai.com/extension) for the current product overview.

### Who is it for?

- **Content creators:** compare openings, formats, and comment questions before drafting an original video.
- **TikTok Shop sellers:** study publicly visible product videos and buyer discussions to improve demonstrations and answer objections.
- **Influencer marketers and agencies:** compare creator content, organize examples, and prepare a brief for human review.
- **Cross-border ecommerce teams:** translate comments and transcripts to understand how a message is received in another market.
- **Social media researchers:** export structured observations and retain a traceable set of public examples for reporting.

Public engagement data describes observed interactions. It does not, by itself, establish sales, conversion rates, or a creator's commercial results.

### Example workflow: from a creator profile to a content brief

1. **Choose a research question.** For example, identify which recent videos lead viewers to ask how a product works.
2. **Open a public profile.** Load the videos you want to compare, then apply sorting and a relevant date window.
3. **Select a small set of examples.** Compare topics and formats alongside engagement; avoid judging a creator from a single unusually popular post.
4. **Read the discussion.** Load and export comments, translate them where needed, and use AI analysis to find repeated questions.
5. **Review the scripts.** Transcribe selected videos and examine how their hooks, explanations, and calls to action differ.
6. **Write an original brief.** Record the examples, questions, proposed angle, and points that still need verification.

This workflow is a suggested way to use the tools, not a promise of higher views or sales.

**Manual installation for Chrome and Edge**

1. Open the [latest release](https://github.com/Jiaye-apple/ai-tiktok-analyzer-pro-releases/releases/latest).
2. Download the appropriate browser ZIP and extract it. Chrome package names include `NEW-STORE-ITEM`; Edge package names include `EDGE`.
3. Open `chrome://extensions` or `edge://extensions`.
4. Enable **Developer mode**, select **Load unpacked**, and choose the extracted folder containing `manifest.json`.
5. Open a public TikTok page and follow the [user guide](https://tiktok.poviai.com/kol/guide).

**Manual installation for Firefox**

Download and extract the `FIREFOX.zip` package. Open `about:debugging#/runtime/this-firefox`, select **Load Temporary Add-on**, and choose the extracted `manifest.json`. Temporary add-ons need to be loaded again after restarting Firefox. This download is not presented as a permanent Mozilla Add-ons installation.

Use the browser ZIP attachments, not GitHub's automatically generated “Source code” archives. Release notes include SHA-256 checksums for checking downloaded packages. Manually installed packages need to be updated manually.

**Can it turn a TikTok video into text?**  
The transcription tools help turn speech into a transcript for review, translation, and script analysis. Speech recognition may need correction, particularly for names, accents, music, and overlapping voices.

**Does it access private profiles or hidden comments?**  
The research workflow works with publicly visible content. It does not grant access to private profiles or comments you cannot view.

**Which interface languages are available?**  
English, Simplified Chinese, Traditional Chinese, Japanese, Korean, Vietnamese, Indonesian, Spanish, and Portuguese.

**Is every feature processed locally?**  
Some tools operate on content in the browser; features such as AI transcription and analysis use server processing. Review the [privacy policy](https://tiktok.poviai.com/privacy) and [security information](https://tiktok.poviai.com/security) before using them.

AI TikTok Analyzer Pro is an independent product, not affiliated with, endorsed by, or sponsored by TikTok or ByteDance. Download and reuse content only when you have authorization.

## 简体中文

### AI TikTok Analyzer Pro 是什么？

AI TikTok Analyzer Pro 是一款结合浏览器插件与网页工作台的 TikTok 内容研究工具，面向短视频创作者、达人营销团队、TikTok Shop 卖家、代理机构和跨境电商团队。它将公开视频排序、评论导出、字幕转写、评论翻译、AI 脚本分析与内容整理放在同一套工作流程中。

浏览 TikTok 时，你可以筛选值得研究的视频，把评论整理成表格，将口播转换为文字，再对比不同内容的开头、结构和观众反馈。网页工作台提供相关工具入口，方便围绕一个选题、一个达人或一类产品持续整理研究材料。

### 核心功能

| 功能 | 可以做什么 | 适用场景 |
|---|---|---|
| TikTok 视频排序与筛选 | 按播放、点赞、评论、分享或发布时间整理已加载的视频，并结合关键词、日期与指标范围筛选。 | 查找值得分析的公开视频，缩小内容研究范围。 |
| TikTok 评论导出 | 将已加载的公开评论导出为表格，保留可获取的评论文本、点赞、时间与回复关系等字段。 | 用户反馈整理、选题调研、报告制作。 |
| 评论翻译 | 阅读评论译文，并对照原文理解表达。 | 跨语言市场研究与海外受众分析。 |
| AI 评论分析 | 整理评论中的高频主题、情绪、常见问题与疑虑。 | 提炼内容方向，寻找产品讲解需要补充的信息。 |
| 视频转文字与字幕处理 | 将视频语音转为文本，查看可用字幕，并配合翻译阅读脚本。 | 口播复盘、多语言内容理解、创作资料整理。 |
| AI 开头与脚本分析 | 拆解视频开头、论述顺序、核心信息和行动引导。 | 比较内容结构，为原创脚本准备思路。 |
| 达人内容分析 | 查看可获取的主页信息与视频互动指标。 | 初步筛选合作对象，比较不同创作者的内容表现。 |
| 单条与批量下载 | 下载你有权使用的视频，或保存筛选后的授权素材。 | 合规的参考资料归档与内容复盘。 |
| 标签研究 | 观察已加载内容使用的标签，并通过网页工具探索话题。 | 选题分类、标签整理与内容规划。 |
| 研究收藏 | 整理选中的达人和视频，建立便于回访的收藏。 | 按项目持续跟进研究材料。 |

视频排序、页面统计和评论分析受到当前已加载内容的影响。导出的评论是实际采集到的样本，不代表全部观众意见；公开互动指标也不能直接证明销量、转化率或商业收益。具体功能和使用额度以当前浏览器、账号及套餐为准。

查看[插件完整功能介绍](https://tiktok.poviai.com/extension)，了解各工具的当前使用方式。

### 哪些人适合使用？

- **短视频创作者：** 从公开视频与评论中寻找问题、比较表达方式，形成自己的选题和脚本。
- **TikTok Shop 卖家：** 研究公开商品内容与买家讨论，整理产品演示需要回答的问题。
- **达人营销与代理团队：** 对比创作者内容，整理参考视频，为合作沟通准备具体材料。
- **跨境电商团队：** 翻译评论和口播，理解不同市场中的表达习惯、需求与疑虑。
- **内容研究人员：** 将公开观察整理为可筛选的表格，为报告保留原始例子和上下文。

### 示例流程：从达人主页整理出一份选题简报

1. **先明确问题。** 例如，最近哪些产品视频引发了观众对使用方法的讨论？
2. **加载并筛选视频。** 打开公开主页，加载要比较的内容，按时间窗口与互动指标缩小范围。
3. **选择一组参考例子。** 同时记录内容主题和形式，避免仅凭一条高播放视频评价整个账号。
4. **整理评论反馈。** 加载评论后导出表格，必要时翻译，再利用 AI 辅助归纳重复出现的问题。
5. **分析口播与结构。** 对选定视频进行转写，比较开头、讲解顺序和行动引导。
6. **形成原创方案。** 写清参考例子、受众问题、拟采用的表达角度，以及仍需人工确认的信息。

这是一种工具使用方法，不代表对播放量、涨粉或成交效果的承诺。

日常使用优先选择[Chrome 商店安装](https://chromewebstore.google.com/detail/ai-tiktok-analyzer-pro-vi/pcbibhdmlmpempoilbklpicngcndepgc)或[Edge 商店安装](https://microsoftedge.microsoft.com/addons/detail/okmglmemcolofokocjhncoaibejejkkd)。需要手动安装时，进入[最新版本下载页](https://github.com/Jiaye-apple/ai-tiktok-analyzer-pro-releases/releases/latest)。
