# AI TikTok Analyzer Pro

本仓库仅用于公开发布浏览器插件安装包，不包含后端源码或开发历史。

[下载最新版本](https://github.com/Jiaye-apple/ai-tiktok-analyzer-pro-releases/releases/latest) · [产品官网](https://tiktok.poviai.com)

## 安装

- Chrome / Edge：下载对应 ZIP，解压后在扩展管理页面启用开发者模式，选择“加载已解压的扩展程序”。
- Firefox：优先使用商店签名版本；此处 ZIP 可通过 about:debugging 临时加载 manifest.json，浏览器重启后需要重新加载。

Release 中 GitHub 自动生成的 Source code 压缩包只包含本发布仓库的说明文件，不是插件安装包。请下载名称包含浏览器类型的 ZIP 附件。

浏览器插件运行所需的 JavaScript 包含在安装包内；后端实现不随包发布。
